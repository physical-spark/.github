# Physical Spark

The hiring standard for a factory's first physical AI engineer.

## What we do

- **Train** - hands-on cohorts that turn software engineers into Physical AI Forward Deployed Engineers.
- **Prove** - every mission is a recorded run, peer-reviewed in the open. Verified work, not resume claims.
- **Place** - manufacturers hire from a leaderboard of engineers whose work they can inspect themselves.

## For engineers

1. Build your project in **your own** GitHub account. You keep it forever.
2. Open a pull request to `showcase` to add your entry.
3. We review it, merge it, and it goes live on our site.
