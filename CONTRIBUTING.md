# Contributing

Thanks for helping out. This guide covers every Physical Spark repo.

## Before you start

- Search open issues first. Someone may already be on it.
- For anything large, open an issue and get agreement before writing code.

## How to contribute

1. Fork the repo.
2. Create a branch: `feat/short-name` or `fix/short-name`.
3. Make your change. Keep it small and focused.
4. Open a pull request. Fill in the template.
5. A maintainer reviews it, usually within 3 business days.

## Rules

- One pull request, one purpose.
- Write commit messages in the imperative: "Add showcase entry", not "Added".
- **Never commit secrets.** No API keys, no `.env` files, no tokens.
- **Never commit personal data.** No real names, emails, phone numbers, or payment info.

## Reporting a security problem

Do not open a public issue. See [SECURITY.md](SECURITY.md).
